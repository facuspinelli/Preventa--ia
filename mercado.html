🚀 Inteligencia de Mercado

Este módulo permite construir un modelo de mercado basado en datos reales, fuentes verificables, supuestos configurables y cálculos transparentes de TAM, SAM y SOM.

El modelo combina información real del Motor de Mercado 360 con escenarios comerciales editables.

✅ Modelo conectado
El Motor de Mercado 360 utiliza datos reales procesados por OEDE para identificar empresas, empleo, industrias y potencial de mercado.

El histórico 2022 de Digitalización continúa funcionando como modelo independiente.

🌐 Mercado 360 · TAM / SAM / SOM

El Mercado 360 combina empresas e industrias reales procesadas por OEDE con la afinidad de cada producto, necesidad documental y supuestos comerciales editables.
🟢 Datos reales: empresas y empleo provenientes de OEDE.
🔵 Cálculos: afinidad, potencial, empresas potenciales, TAM, SAM y SOM.
🟡 Supuestos: porcentaje de empresas objetivo, SAM, SOM y precio.
🔴 Precio faltante: mientras el precio sea 0 no se inventará un valor económico.

🧠 Trazabilidad del modelo

La lógica utilizada diferencia claramente datos reales, cálculos y supuestos.
Cadena de cálculo Mercado 360:

Empresas OEDE → Industria → Necesidad documental → Afinidad producto / industria → % empresas objetivo → Empresas potenciales → Precio anual → TAM → % SAM → SAM → % SOM → SOM
